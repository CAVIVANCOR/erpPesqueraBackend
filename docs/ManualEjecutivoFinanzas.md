🎯 RESUMEN EJECUTIVO
El Módulo de Finanzas le permite gestionar y controlar en tiempo real toda la tesorería avanzada de su empresa: préstamos bancarios, líneas de crédito e inversiones financieras. Este módulo automatiza cálculos, genera reportes y le proporciona visibilidad completa del estado financiero de su organización.

Beneficios Clave para la Gerencia:
✅ Control Total: Visibilidad en tiempo real de obligaciones e inversiones
✅ Automatización: Cálculo automático de cuotas, intereses y rendimientos
✅ Trazabilidad: Registro completo de desembolsos, garantías y movimientos
✅ Reportes Ejecutivos: Información consolidada para toma de decisiones
✅ Integración Contable: Conexión automática con asientos contables y movimientos de caja

💼 1. PRÉSTAMO BANCARIO
¿Qué hace?
Registra y controla todos los préstamos bancarios de la empresa, calculando automáticamente las cuotas, intereses y manteniendo actualizado el saldo de capital.

Información que Gestiona:
┌─────────────────────────────────────────────────────────────┐
│                    PRÉSTAMO BANCARIO                        │
├─────────────────────────────────────────────────────────────┤
│ • Datos del Préstamo (monto, tasa, plazo, tipo)             │
│ • Cronograma de Cuotas (capital, interés, fechas)           │
│ • Desembolsos Recibidos (fechas, montos, documentos)        │
│ • Garantías Asociadas (hipotecarias, prendarias, fianzas)   │
│ • Documentación (contratos, pagarés, anexos)                │
└─────────────────────────────────────────────────────────────┘
Flujo de Información:
1. REGISTRO DEL PRÉSTAMO
   ↓
2. GENERACIÓN AUTOMÁTICA DE CRONOGRAMA DE CUOTAS
   ↓
3. REGISTRO DE DESEMBOLSOS (cuando el banco entrega el dinero)
   ↓
4. REGISTRO DE GARANTÍAS (respaldo del préstamo)
   ↓
5. PAGO DE CUOTAS (actualización automática de saldos)
   ↓
6. INTEGRACIÓN CONTABLE (asientos automáticos)
Ejemplo Práctico:
Concepto	Valor
Préstamo Solicitado	S/ 500,000
Tasa de Interés	12% anual
Plazo	24 meses

Desembolsos Recibidos	S/ 500,000 (100%)
Saldo Actual	S/ 350,000 (después de 8 cuotas)
Reportes Disponibles:
📊 Cronograma completo de pagos
💰 Saldo de capital pendiente
📈 Intereses pagados vs. proyectados
🔒 Estado de garantías
💳 2. LÍNEA DE CRÉDITO
¿Qué hace?
Controla las líneas de crédito aprobadas por bancos, mostrando en tiempo real cuánto crédito tiene disponible y cuánto está utilizando.

Información que Gestiona:
┌─────────────────────────────────────────────────────────────┐
│                    LÍNEA DE CRÉDITO                         │
├─────────────────────────────────────────────────────────────┤
│ • Límite Aprobado                                           │
│ • Monto Utilizado                                           │
│ • Monto Disponible                                          │
│ • % de Utilización                                          │
│ • Fecha de Vencimiento                                      │
│ • Estado (Vigente, Vencida, Suspendida)                     │
└─────────────────────────────────────────────────────────────┘
Flujo de Información:
1. REGISTRO DE LÍNEA DE CRÉDITO APROBADA
   ↓
2. ASOCIACIÓN CON PRÉSTAMOS (cuando se usa la línea)
   ↓
3. ACTUALIZACIÓN AUTOMÁTICA DE MONTOS UTILIZADOS
   ↓
4. MONITOREO DE DISPONIBILIDAD EN TIEMPO REAL
   ↓
5. ALERTAS DE VENCIMIENTO
Ejemplo Práctico:
Concepto	Valor	%
Límite Aprobado	USD 1,000,000	100%
Utilizado	USD 650,000	65%
Disponible	USD 350,000	35%
Estado	🟢 VIGENTE	-

🟡 61-80%: Precaución, considerar ampliación

📈 3. INVERSIÓN FINANCIERA
¿Qué hace?
Registra y controla las inversiones de la empresa (plazos fijos, fondos mutuos, bonos), calculando automáticamente rendimientos y valorizaciones.

Información que Gestiona:
┌─────────────────────────────────────────────────────────────┐
│                  INVERSIÓN FINANCIERA                       │
├─────────────────────────────────────────────────────────────┤
│ • Monto Invertido                                           │
│ • Tasa de Rendimiento                                       │
│ • Valor Actual (actualizado con movimientos)                │
│ • Rendimiento Acumulado                                     │
│ • Movimientos (aportes, retiros, rendimientos)              │
│ • Estado (Vigente, Vencida, Liquidada)                      │
└─────────────────────────────────────────────────────────────┘
Flujo de Información:
1. REGISTRO DE INVERSIÓN INICIAL
   ↓
2. REGISTRO DE MOVIMIENTOS:
   - INVERSIÓN: Aportes adicionales
   - RENDIMIENTO: Intereses ganados
   - RETIRO: Retiros parciales
   - AJUSTE: Correcciones de valor
   - LIQUIDACIÓN: Cierre de inversión
   ↓
3. ACTUALIZACIÓN AUTOMÁTICA DE VALOR ACTUAL
   ↓
4. CÁLCULO DE RENDIMIENTO ACUMULADO
   ↓
5. INTEGRACIÓN CONTABLE
Ejemplo Práctico:
Concepto	Valor
Inversión Inicial	S/ 200,000
Tasa Anual	8.5%
Plazo	12 meses
Rendimientos Acumulados	S/ 17,000
Valor Actual	S/ 217,000
Rentabilidad Real	8.5%
Tipos de Movimientos:
Tipo	Efecto	Ejemplo
INVERSIÓN	➕ Aumenta valor	Aporte adicional de S/ 50,000
RENDIMIENTO	➕ Aumenta valor	Intereses del mes: S/ 1,417
RETIRO	➖ Disminuye valor	Retiro parcial de S/ 30,000
AJUSTE	➖ Disminuye valor	Comisión bancaria: S/ 500
LIQUIDACIÓN	➖ Cierra inversión	Retiro total al vencimiento

6. CÓDIGO IMPLEMENTADO
Backend - Cambio Automático de Estado
javascript
// 📁 prestamoBancario.service.js - Función crear()
const prestamo = await prisma.$transaction(async (tx) => {
  // Crear nuevo préstamo
  const nuevoPrestamo = await tx.prestamoBancario.create({
    data: { ...data, saldoCapital, saldoInteres, capitalPagado, interesPagado }
  });
  // Crear cuotas
  await tx.cuotaPrestamo.createMany({
    data: cuotas.map(cuota => ({
      ...cuota,
      prestamoBancarioId: nuevoPrestamo.id
    }))
  });
  // ⚡ LÓGICA DE REFINANCIAMIENTO
  if (data.esRefinanciamiento && data.prestamoRefinanciadoId) {
    await tx.prestamoBancario.update({
      where: { id: data.prestamoRefinanciadoId },
      data: { estadoId: BigInt(84) } // Estado REFINANCIADO
    });
  }
  return nuevoPrestamo;
});
